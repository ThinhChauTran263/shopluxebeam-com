# LuxeBeam Shopify Theme

A modern, responsive Shopify theme for aesthetic lighting products.

## Theme Structure

```
├── assets/           # CSS, JS, images, fonts
├── blocks/           # Reusable content blocks
├── config/           # Theme settings and configuration
├── layout/           # Theme layout files
├── locales/          # Translation files
├── sections/         # Theme sections
├── snippets/         # Reusable code snippets
└── templates/        # Page templates
```

## Features

- ✅ Fully responsive design
- ✅ Modern JSON template system
- ✅ Product variants & cart functionality
- ✅ Collection filtering & sorting
- ✅ AJAX cart updates
- ✅ Search functionality
- ✅ SEO optimized
- ✅ Accessibility compliant
- ✅ Performance optimized

## Key Files

### Templates
- `index.json` - Homepage layout
- `product.json` - Product page layout
- `collection.json` - Collection page layout
- `cart.json` - Shopping cart layout

### Sections
- `main-product.liquid` - Product display
- `main-collection-product-grid.liquid` - Product grid
- `main-cart.liquid` - Cart functionality
- `slideshow.liquid` - Homepage hero slider
- `featured-collection.liquid` - Product showcase

### Assets
- `theme.js` - Main theme JavaScript
- `fonts.css` - Google Fonts (Figtree & Inter)
- `base.css` - Base theme styles
- `shopify_v2.css` - Additional styles

## Installation

1. Upload theme files to Shopify admin
2. Configure theme settings in admin panel
3. Customize sections and blocks as needed

## Customization

The theme uses Shopify's modern JSON template system for easy customization:

- Edit section settings in theme editor
- Modify templates in `templates/` directory
- Add custom CSS in `assets/base.css`
- Extend functionality in `assets/theme.js`
